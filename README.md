# AI Sentiment Analysis App

An AI-powered Sentiment Analysis Web Application built using Python, Gradio, and NLP.

## Features

- Detects whether the text is **Positive**, **Negative**, or **Neutral**
- Shows Polarity Score (-1 to +1)
- Provides simple explanation of the result
- Clean and interactive web interface
- Example texts included for easy testing

## Technologies Used

- Python
- Gradio
- TextBlob (NLP)
- Natural Language Processing (NLP)

## How to Run

1. Open the notebook in Google Colab
2. Install required libraries
3. Run all cells
4. Click on the public Gradio link to use the app
